# Guía Interactiva: Relaciones Ecológicas en los Ecosistemas

Material educativo interactivo para el área de Ciencias Naturales, diseñado para facilitar el aprendizaje sobre las relaciones intraespecíficas e interespecíficas, dirigido a estudiantes de educación secundaria.

## Características
- **Guía Teórica:** Conceptos fundamentales sobre competencia, simbiosis, parasitismo, entre otros.
- **Cuestionario Anti-Sesgo:** 15 preguntas con opciones de respuesta de redacción similar para fomentar el análisis profundo y la comprensión real del estudiante.
- **Temporizador de Análisis:** Integración de una pausa obligatoria de 30 segundos por pregunta para asegurar la lectura.
- **Retroalimentación Visual:** Animaciones y sistema de confeti para los estudiantes que aprueben (Nota >= 3.7).

## Estructura de Archivos
- `index.html`: La estructura semántica del sitio, donde se encuentra la teoría y el marco del quiz.
- `style.css`: Hojas de estilo modernas, responsivas y con variables de color ecológicas.
- `script.js`: Lógica del cuestionario, validación, temporizador y cálculo de notas.
- `README.md`: Este archivo de documentación.

## Instrucciones para subir a GitHub Pages
1. Crea un nuevo repositorio en tu cuenta de GitHub (ej: `guia-ecologia`).
2. Sube los archivos `index.html`, `style.css` y `script.js` a la rama `main` o `master`.
3. Dirígete a la pestaña **Settings** (Configuración) del repositorio.
4. En el menú lateral izquierdo, haz clic en **Pages**.
5. En la sección "Source", selecciona tu rama (`main` o `master`) y guarda.
6. En unos minutos, GitHub te proporcionará un enlace público (ej: `https://tu-usuario.github.io/guia-ecologia/`) que podrás compartir con tus estudiantes.
